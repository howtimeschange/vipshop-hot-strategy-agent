# Safety Boundary

这个项目默认只做 read-only 数据采集和离线分析。

## 浏览器边界

- 默认连接用户已经登录的 `http://127.0.0.1:9222` Chrome/CDP 会话。
- 优先复用当前页面的 page-owned API 或已验证请求路径。
- 不打开新的登录容器来替代用户当前会话。
- 不读取、打印、保存或转存 cookie、token、localStorage、sessionStorage、二维码、身份信息、支付信息。

## 动作边界

允许：

- 观察页面状态。
- 调用页面上下文中的只读报表接口。
- 分页读取报表数据。
- 导出本地 Excel、JSON、Markdown 文件。

禁止，除非用户对具体动作再次明确授权：

- 提交、保存、发布、删除、付款、下单。
- 批量修改营销活动、预算、出价、券、礼金、人群或商品配置。
- 把登录态、令牌或个人敏感信息写入项目文件、日志或报告。

## 验证要求

- 采集成功要输出工作簿路径、总行数和各 sheet 行数。
- 分析成功要输出 `analysis.json` 和 `strategy.md` 路径。
- 权限、接口或页面结构变化时，报告具体失败点，不把空表误判为业务无数据。
