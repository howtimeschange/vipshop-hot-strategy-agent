# Metrics And Rules

本引用文件把 `docs/爆款策略追踪agent-需求文档.docx` 的业务口径压缩成 CLI 和 skill 可执行规则。

## 五报表数据层

| 报表 | 主要作用 | 当前判断重点 |
| --- | --- | --- |
| 魔方罗盘销售明细 | 商品销售、流量、点击、转化、价格、库存 | 商品承接能力、过程指标基线、库存干扰 |
| 唯直达投放效果 | 搜索/站内广告投放 | 花费、曝光、点击、CTR、24 小时订单额、ROI |
| T-max 商品打爆效果 | 商品粒度投放 | 活动成本、曝光、点击、收藏、加购、销售额、ROI |
| 中台礼金 | 礼金权益成交 | 使用销售额、订单、活动成本、ROI、自然成交替代风险 |
| 中台购物车/跨品类券 | 购物车挽回和券成交 | 用券成交、活动成本、ROI、活动周期复盘 |

## 三层判断框架

1. 机制判断：核心过程指标是否改善，比如点击率、商详 UV、转化率、加购、收藏。
2. 可信度判断：辅助指标是否支持归因，重点看曝光分母、绝对点击量、价格、库存、广告、权益、售后和参考组。
3. 商业判断：销售额、订单、客户、ROI、成本和经营质量是否健康。

最终建议必须落到动作：保留、放大、回滚、继续观察、拆分实验或补数据后再判断。

## 默认效果标签

| 条件 | 效果标签 | 置信度 |
| --- | --- | --- |
| ROI >= 8 且有成交量 | 商业效率健康 | 高 |
| ROI >= 3 且有成交量 | 可继续观察/局部放大 | 中 |
| ROI > 0 | 效率偏弱 | 中 |
| 无成交或无成本口径 | 暂无法判断 | 低 |

这些阈值是当前 CLI 的保守默认值。后续接入品类、价格带、生命周期和毛利后，应把阈值迁移成可配置规则。

## 动作类型映射

| 动作类型 | 核心过程指标 | 辅助校验 | 终端指标 |
| --- | --- | --- | --- |
| 主图/主图文案 | 商品点击率、商详 UV | 曝光 UV、点击绝对量、价格、库存、广告花费 | 销售额、客户数 |
| 微详情/详情页 | 购买转化率 | 商详 UV、加购率、收藏率、价格、库存、售后 | 销售额、不含拒退销售额 |
| 颜色词/单色卖点 | 单色转化率 | 同款未优化货号、单色 UV、库存、价格 | 单色销售额、整体款销售额 |
| 搭配购 | 低曝光款曝光 UV、商详 UV | 高曝光款流量变化、低曝光款转化、库存 | 低曝光款销售额、组合相关款销售额 |
| e-Tmax/唯直达投放 | 曝光、点击、CTR、CPC | 收藏、加购、加购成本、价格、库存、自然流量 | 24 小时销售额、ROI、整体销售额 |
| 礼金/购物车挽回 | 使用人数、使用量、订单数 | 使用销售额、成本、价格、库存、自然成交替代 | 使用销售额、ROI、整体销售净变化 |

## 当前数据缺口

- 动作记录和产品基础信息未进入默认采集，因此单任务实验组/参考组净效应还不能自动生成。
- 唯直达和 T-max 分日、关键词、商品粒度越完整，广告干扰判断越可信。
- 礼金和券缺触达、打开、点击、领取、毛利时，只能判断用后成交效率，不能完整判断利润健康。
- 库存天数低、价格明显变化、活动叠加时，置信度必须降级。
